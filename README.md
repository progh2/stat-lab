# 기초 통계량 실험실

> 📊 고등학생을 위한 기초 통계량 인터랙티브 학습 페이지

🔗 **[지금 바로 열기 → https://progh2.github.io/stat-lab/](https://progh2.github.io/stat-lab/)**

---

## 소개

평균·중앙값·최빈값부터 범위·분산·표준편차·사분위수까지, **직접 값을 바꾸고 손으로 계산하며** 통계량의 의미를 체득하는 단일 HTML 학습 앱입니다. 별도 설치 없이 브라우저로 바로 열 수 있습니다. 막히는 지점에는 반 친구 **하나**가 짧은 말풍선으로 옆에서 짚어 줍니다.

> 이 페이지는 **[인공지능 파이썬 기초](https://www.mtrschool.co.kr/post/3096)** 교재의 기초 통계량 챕터 내용 이해를 돕기 위해 제작되었습니다.

## 주요 기능

| 단원 | 내용 |
|------|------|
| 도입 | 평균 70점인 두 반 비교 → 퍼짐을 배운 뒤 표준편차·IQR을 구해 답을 닫음 |
| ① 중심값 | 평균·중앙값·최빈값 개념 카드 + 손계산 연습 + 점 도표 실험실(이상치·좌우 꼬리) |
| ② 퍼짐 | 범위 비교, 분산·표준편차 워크시트, 슬라이더 히스토그램, Tukey 사분위수·IQR·상자그림 |
| ③ 데이터 파악 | 기존 3종 계산 + “어떤 숫자를 쓸까” 해석 + 우리 반 점수 붙여넣기 계산기 |
| ④ 형성평가 | 약 100문항 풀, 20/40/전체 · 순서/랜덤, 즉시 채점 |
| ⑤ 미리보기 | 68–95–99.7 경험 규칙 (선택, 평가 제외) |
| 기타 | 단원 체크·진행률(브라우저에 기억), 컨페티 팡파레, 효과음 on/off, 흔한 오해 카드 |

[https://progh2.github.io/stat-lab/](https://progh2.github.io/stat-lab/) 접속

빌드 단계는 없습니다. `index.html`을 그대로 열면 됩니다.

## 단원 구성

```
도입  두 반(평균은 같고 퍼짐은 다름) → ②에서 SD·IQR로 닫기
①    자료의 중심   → 평균 / 중앙값 / 최빈값
②    자료의 퍼짐   → 범위 / 편차 / 분산 / 표준편차 / 상자그림
③    데이터 파악   → 계산 + 대푯값 선택 + 한 문장 해석 + 붙여넣기 계산기
④    형성평가      → 약 100문항 중 20·40·전체 (순서 또는 랜덤)
⑤    선택 미리보기 → 68–95–99.7 (형성평가에 없음)
```

## 계산 규칙 (이 페이지의 정답 기준)

- **분산·표준편차**는 모집단 공식(**÷n**)입니다. 엑셀 `STDEV.S` / 표본 표준편차(n−1)와 다를 수 있습니다.
- **사분위수**는 **Tukey 방식**(중앙값을 아래·위 절반에 넣지 않음)입니다. 엑셀 `QUARTILE.INC`와 다를 수 있습니다.
- **최빈값**: 모든 값이 한 번씩만 나오면 없음. 가장 많이 나온 값이 둘 이상이면 쌍봉·다봉(모두 최빈값).
